# PWA Screenshots

This directory contains screenshots for the PWA manifest.

## Required Screenshots

- desktop-home.png (1280x720)
- mobile-home.png (540x720)

## How to Generate Screenshots

### Option 1: Using Browser DevTools
1. Open the website in Chrome/Edge
2. Press F12 to open DevTools
3. Click the device toolbar icon (Ctrl+Shift+M)
4. Select device:
   - Desktop: 1280x720
   - Mobile: iPhone SE (375x667) or similar
5. Take screenshot: Ctrl+Shift+P > "Capture screenshot"
6. Save to this directory with appropriate name

### Option 2: Using Lighthouse
1. Open Chrome DevTools
2. Go to Lighthouse tab
3. Run PWA audit
4. Screenshots will be generated automatically
